## 概要
サイト全ページのコンテンツをNotion管理化し、/admin 管理画面を大幅に再構成した。

## 背景・課題
- About・TOPページのコンテンツがすべてハードコードされており、更新のたびにコードを触る必要があった
- 管理画面が提案・実績のみ対応で、About/TOPページは対象外だった
- OGP画像・プロフィール写真の仕組みがなかった

## 決定内容

### 1. About DBの拡張（NOTION_ABOUT_DB_ID）
既存のDBに `section` プロパティで全コンテンツを一元管理：

| section値 | 用途 | titleキー例 |
|---|---|---|
| journey | 経歴（既存） | 見出し |
| misc | SNSリンク（既存） | 表示名 |
| skills | スキルリスト | スキル名（bodyにグループ名） |
| profile | プロフィール情報 | catch_copy / intro / Base / Available / Type / og_image / avatar |
| philosophy | TOPのPhilosophy | 問い（bodyに答え、sub_labelに説明文） |
| process | TOPのProcess | 英語名（sub_labelに日本語名） |
| about_stats | TOPのAbout欄右カラム | Role / Focus / Stack / Belief |
| works_capability | TOPのWorksカード | カテゴリ名（urlフィールドをラベルとして流用） |

### 2. 管理画面の再構成
- 管理トップ → ダッシュボードカード形式（実績管理・TOPページ管理・Aboutページ管理）
- /admin/about → Aboutページ専用（Journey/Misc/Skills/Profile）
- /admin/top → TOPページ専用（Philosophy/Process/About欄/Works）
- 共通EditorロジックをSectionEditor（app/admin/_components/SectionEditor.tsx）に集約
- 各タブに用途説明・Notion操作が必要な箇所には黄色警告パネルを追加

### 3. OGP・画像対応
- app/opengraph-image.tsx → サイト全体のOGP自動生成（キャッチコピー入り1200×630）
- app/about/opengraph-image.tsx → Aboutページ用OGP
- profile > og_image にURLを設定するとカスタムOGP画像として優先使用
- profile > avatar → Aboutページのプロフィール写真（public/avatar.png がデフォルト）
- ImageResponse内のdivはすべてdisplay:flexが必須（Next.js制約）

### 4. その他
- react-icons導入：X / Instagram / Threads / GitHub / Note のアイコンをContact・Miscに追加
- Contact：「話しましょう」→「お聞かせください」、ホバーをコンテナ全体に
- Philosophy の強調テキストはNotionで文字に色付けすると反映（rich_text annotationを取得）
- intro（自己紹介文）はTOPとAboutで共通使用（intro_topは廃止）

## 採用しなかった選択肢と理由
- 複数のNotion DBに分散管理 → 環境変数が増えるため、1つのDBにsectionで統合
- ハードコードのまま残す部分を作る → 管理の一貫性のため全部Notion化を選択
- Notionのアップロード画像をOGP/avatarに使う → 有効期限1時間の問題があるため外部URLまたはpublic/を推奨

## 注意事項・今後の課題
- Notionのキャッシュは5分（revalidate: 300）。変更後5分で反映される
- philosophy の答えの強調テキストはこの管理画面UIから設定不可。Notion上で文字を選択し色を付ける必要がある
- works_capability の「ラベル」フィールドはNotionの `url` プロパティを流用している（名前が紛らわしい）
- プロフィール写真（public/avatar.png）の変更は現在ファイル差し替え＋コミットが必要。頻繁に変える場合はprofile > avatarにURLで設定する方法もある
- Skillsグリッド左カラムは md:pr-16 が必要（一度消えてバグになった。再発注意）
